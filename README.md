# MusicMine

Multi-platform music streaming and discovery web application featuring a custom AMOLED Red & Black design system, persistent audio engine, playlist management, and catalog curation.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Configure environment variables in `.env` (refer to `.env.example`):
   ```bash
   cp .env.example .env
   ```
3. Run the application:
   ```bash
   npm run dev
   ```
